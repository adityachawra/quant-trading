# Quant Trading — 90 Day Roadmap Project

Personal quant trading infrastructure, based on Ernest Chan's *Quantitative Trading* (2nd ed.), adapted for Indian retail (NSE).

## Structure
- `data/` — ingestion scripts
- `strategies/` — one folder per strategy
- `backtest/` — backtesting engine, cost model, metrics
- `logs/` — trade logs, weekly notes
- `tests/` — unit tests
